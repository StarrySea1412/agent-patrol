DESIGN NOTE · rules.py 模块注释第一行（原文）

「Deterministic rule engine: runs before any LLM. AI narrates and deep-dives, rules decide facts.」——确定性规则引擎，先于任何大模型运行；AI 负责叙事与深挖，事实由规则决定。

这行注释是整台 Agent 的宪法，也是它和「把大模型接上监控数据」这类产品的分水岭：分数、告警、根因卡的骨架全部出自确定性代码，AI 的每句话都被钉在「附加视角」的位置上。本篇就沿着这条宪法往下拆。

巡检是运维里最老的一门手艺，也是最容易被「接入大模型」冲昏头的一门。这台 Agent 的做法近乎固执：先写死一套确定性规则——磁盘 85% 警告、95% 严重、恢复必须回落到 80% 以下；再写一台不依赖任何库的 DNS 栈和一段直插 iphlpapi 的 ICMP；健康分对同类告警按 0.5ⁿ 衰减，免得十条「磁盘 86%」把分数砸穿；根因卡的结论永远来自规则事实，AI 叙事挂了就挂着，诊断照常出卡。到最危险的修复环节，它立了全篇最硬的一条铁律：批准只是记录决策，执行是批准之后另一个显式动作——默认关闭，逐段白名单，一切留痕。
